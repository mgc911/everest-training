# Everest Training

Calendario semanal (lunes a domingo) para organizar quedadas al rocódromo en grupo.
Cada persona entra con su nombre, propone un día y una hora, y el resto responde si va o no.

- Next.js (App Router), desplegado en Vercel.
- Datos guardados en Vercel Blob (variable `BLOB_READ_WRITE_TOKEN`).

```bash
npm install
npm run dev
```
